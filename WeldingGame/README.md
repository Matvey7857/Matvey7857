# Welding Game Mechanics

This folder contains example scripts for implementing a simple welding mechanic in Roblox using Luau. The mechanic allows the player to weld blocks together while completing random tasks that refresh in the UI.

The code is organized as follows:

- `src/WeldingMechanic.lua` – A module handling the welding logic.
- `src/TaskManager.lua` – Creates and updates tasks for the player.
- `src/GUIController.lua` – Demonstrates how tasks can be displayed in the user interface.

These scripts are not a complete game but provide a starting point for integrating welding tasks into a project.
